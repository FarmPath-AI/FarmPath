# FarmPath

## Northern Nigeria's AI Farming Assistant

**From Land Preparation to Harvest — Your Farm, Guided by AI.**

### Prototype features
- Local browser authentication demo
- Farm registration and persistence
- Personalized farming workflow/calendar
- Today's FarmPath dashboard
- Crop Doctor workflow interface
- Farm Money Manager
- Responsive mobile-first design

## Run
Open `index.html` in a browser, or upload all files to GitHub Pages.

## Important
This prototype uses browser localStorage so it works immediately without a backend.
For production, replace localStorage with Supabase/database authentication and connect:
- a weather provider
- validated crop-diagnosis AI
- verified Nigerian agricultural guidance
- official pesticide registration/product data
